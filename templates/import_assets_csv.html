📋 CSV Format Instructions

Your CSV file must include a header row with the following column names exactly:

  • asset_name: Name of the asset (e.g., Lenovo ThinkPad X1)
  • asset_id: Unique identifier (e.g., LP-00125)
  • asset_tag: Unique barcode tag (e.g., TAG-8812)
  • asset_type: Type of asset. Valid types: Laptop, Desktop, Monitor, Printer, Phone, Server, Tablet, Keyboard, Mouse, Other
  • brand: Manufacturer brand (e.g., Lenovo)
  • model: Model name or number (e.g., X1 Carbon)
  • serial_number: Unique hardware serial number
  • purchase_date: Format must be YYYY-MM-DD (e.g., 2026-08-26)
  • price: Numeric value of the purchase price (e.g., 1200.50)
  • description: (Optional) Any extra notes or description

⚠️ Note: The CSV import runs inside a database transaction. If any row has validation errors (e.g. duplicate IDs or wrong date formats), all insertions will be rolled back so no partial data is saved.
