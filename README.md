# IT Asset & Helpdesk Ticketing System

A Django-based web application for managing IT assets and handling employee helpdesk tickets efficiently.

## 🚀 Live Website

[Visit Live Website](https://it-asset-helpdesk-ticketing-system.onrender.com)

## ✨ Features

- Employee and IT Support roles
- Hardware asset management
- Software license management
- Asset assignment to employees
- Helpdesk ticket creation
- Ticket priority and category management
- Ticket status workflow
- Ticket comments
- Admin dashboard
- PostgreSQL database

## 🔄 Ticket Workflow

Open → In Progress → Resolved → Closed

## 🛠️ Tech Stack

- Python
- Django
- PostgreSQL
- HTML
- CSS
- Bootstrap
- Git & GitHub
- Render
